# Python Quiz App

A simple terminal-based quiz application built with Python.

## Features
- Multiple-choice questions (A/B/C)
- Instant feedback on every answer
- Final score shown at the end

## How to Run
```
python quiz.py
```

## Concepts Used
- Lists and dictionaries
- Loops (`for`)
- Conditions (`if/else`)
- User input and f-strings

## Future Improvements
- Add more questions
- Handle invalid input
- Shuffle questions randomly
